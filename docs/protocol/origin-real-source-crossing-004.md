## Exactly what is real in this prototype

The source offer and departure are actual immutable events created by STATIC FIELD's own native kernel in an exported continuation of a native First Bell history. WORLDSEED verifies the source history, native receipts and offer, issues its own scoped admission, accepts a deliberate same-player confirmation, and requires a matching source-owned departure before writing its own arrival event and FirstCrossingReceipt. The resulting session can use FOREIGN ROOM's existing Table reducer; it is not the older synthetic Origin source fixture. The destination's preexisting half-finished meal is *destination-authored fiction*, not an imported personal memory.

Hashes check content consistency and chain linkage; neither GitHub source pinning nor content digests authenticate a real person. The `--confirm` command represents an explicit local test-player decision, **not** a third-party signature. Local file snapshots can fork or be replayed: this prototype does not guarantee globally exactly-once movements, live browser-server state synchronization, or atomic distributed storage. No private memory, source-local Charge, model permission or interpreted Bell cause is transported.

## Player route: actual locally played Porch

Use Node 22 and two separate checkouts. On the STATIC FIELD **source crossing branch**:

```sh
npm install
npm run build
npm start
# Open http://127.0.0.1:4173, play to CLOSE PLAY with the open corner traced.
# Stop the browser server before exporting its event log.
npm run export:played-porch -- --log var/static-field/history.jsonl --out /tmp/breach/played
npm run crossing:source -- --phase offer --from /tmp/breach/played --out /tmp/breach/offered
```

On WORLDSEED's **real source crossing branch**, inspect and choose admission/confirmation:

```sh
node scripts/live-crossing.js --phase prepare --from /tmp/breach/offered --out /tmp/breach/prepared.json
# Review prepared.json. The browser Porch labels its local human actor "human/local-player".
node scripts/live-crossing.js --phase confirm --prepared /tmp/breach/prepared.json --actor human/local-player --confirm --out /tmp/breach/packet.json
```

Back in STATIC FIELD, record source departure against the exact matching destination packet:

```sh
npm run crossing:source -- --phase depart --from /tmp/breach/offered --packet /tmp/breach/packet.json --out /tmp/breach/departed
```

Back in WORLDSEED, ask FOREIGN ROOM to inspect that new source history and record arrival:

```sh
node scripts/live-crossing.js --phase arrive --from /tmp/breach/offered --departed /tmp/breach/departed --packet /tmp/breach/packet.json --out /tmp/breach/arrived.json
```

`arrived.json` contains `session`, `arrivalReceipt`, and `crossingReceipt`. `session` is accepted by `projectTable` and `playLiveTable` from `src/origin/live-crossing.js`. The existing `/origin/` browser demo still boots a **separate synthetic source fixture**; do not mistake it for a UI for this native session. A saved, verification-gated browser carrier is a separate next slice.

If you miss the open corner or fail to trace the relation, the source refuses an offer. No confirmation means no departure. Wrong admission, altered source history, conflicting native receipts, forged departure or backwards arrival refuse rather than invent a successful Crossing.

## Reproducible CI fixture

`.github/workflows/native-breach.yml` checks out a pinned STATIC FIELD source commit, runs both independent test suites, then performs the real compiled-kernel file handoff with `npm run demo:first-bell` as input. That fixture is a synthetic *player path generated by the real STATIC FIELD kernel*, not a claim that anyone personally played the browser. Times are fixed in the workflow to maintain explicit sequence.

Nonclaims: no external-world evidence, no real human identity verification, no automatic destination consent beyond scoped local fictional admission, no private data movement, no source interpretation promoted to event fact, and no authorization to enter any future GRACE world from the Foreign Room's reported address.
